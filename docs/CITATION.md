# Citation guidance

When reusing the data, cite the actual repository URL and version/commit you
used, and credit ECMWF / Copernicus Climate Change Service (C3S). Add the
original CDS retrieval citation once its product metadata are available.
The source request was not supplied, so this package does not assign a
specific CDS catalogue DOI to the extract based only on monthly output labels.

Suggested repository description:

> ERA5 regional 2 m air temperature data and maps. Annual data 1940–2025,
> monthly data January 1940–October 2026, 0.25° grid, 10–60°N and 125–75°W.
> Monthly values average daily 17:00 UTC samples; October 2026 is partial.
> Derived from ECMWF / Copernicus Climate Change Service ERA5 data.

General ERA5 reference:

Hersbach, H., et al. (2020). The ERA5 global reanalysis. *Quarterly Journal
of the Royal Meteorological Society*, 146, 1999–2049.
https://doi.org/10.1002/qj.3803

Map outlines: Natural Earth, 1:110m coastline and administrative boundaries,
public domain. https://www.naturalearthdata.com/

See `DATA_LICENSE.md` for attribution and license terms. No repository owner,
publication DOI, or release URL has been invented for this local package.
